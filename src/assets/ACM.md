# HRD Corp Allowable Cost Matrix (ACM)
Source: ACM Table (November 2025) + ACM Guide (September 2025)

---

## HOW TO USE THE MATRIX

| Step | Action |
|------|--------|
| Step 1 | Determine the type of scheme |
| Step 2 | Determine the type of training (in-house, public, overseas, seminar/conference) |
| Step 3 | Decide on the training venue |
| Step 4 | Choose the type of trainer |
| Step 5 | Find out the allowable cost details by referring to the eligibility section |

> E-Learning, ROT, and Development Programme are NOT in the Matrix table — see separate tables below.

| B) Course Fee — General (Technical), no subsidiary | Full: RM10,500/day/group; Half: RM6,000/day/group | ✗ | ✓ | ✓ |
| B) Course Fee — General, with subsidiary (HCC/SBL only) | Full: RM1,750/pax/day; Half: RM1,000/pax/day | ✗ | ✓ Each company pays per their own pax | ✓ Each company pays per their own pax |
| B) Course Fee — Focus Area / Ind. Specific / Prof Cert | As charged, per pax | ✗ | ✓ | ✓ |
| C) Travel Allowance | <100km: RM250/day/pax; ≥100km: RM500/day/pax | ✓ Branch/sub trainees + trainer if from branch | ✓ Branch/sub trainees + ext. trainer | ✓ Branch/sub trainees only |
| D) Meal Allowance | Full: RM100/day/pax; Half: RM50/day/pax | ✓ Host trainees + trainer (+1 pax) | ✓ Host trainees only | ✓ Host trainees only |
| E) Overseas Trainer Allowance | RM500/day/trainer | ✗ | ✗ | ✓ |
| G) Air Ticket | Actual airfare | ✓ Branch/sub trainees + trainer if from branch | ✓ Branch/sub trainees + ext. trainer (ext. trainer only when branches/subs exist OR venue is hotel) | ✓ Branch/sub trainees + ovs. trainer (ovs. trainer always — flew in from overseas) |
| H) Chartered Transport | As per quotation | ✗ | ✗ | ✗ |
| I) Consumable Materials | RM100/group; >RM100 itemised invoice | ✓ | ✓ | ✓ |
| LTM (Licensed Training Materials) | As charged | ✓ Pre-approval required | ✓ Pre-approval required | ✓ Pre-approval required |

**Notes:**
- C vs D mutual exclusivity: each person claims C (travel) OR D (meal) — not both. Host trainees → D. Branch/sub trainees → C.
- External trainer may claim C only — not D.
- Overseas trainer gets E (daily allowance), not D (meal).
- A and B prorated when total pax < 5.
- Extra travel day: staff ≥100km may claim +1 extra day at Row C rate (full day training only).
- Subsidiary present (HCC/SBL): public rate (RM1,750/pax/day) applies for both external and overseas trainer. Each company pays per their own pax.
- SLB cost mode: group rate ÷ total pax × each employer's pax. Never switches to public rate.
- SLB consumables: organising employer only.
- SLB: overseas trainer not applicable.
- Max pax per group (Employer's Circular No. 3/2024): Non-Technical = 50 pax × number of trainers; Technical = 25 pax × number of trainers. **This is a hard limit — exceeding it blocks the grant application. Reduce participants or add trainers.**
- **Actual Course Fee (External/Overseas trainer):** Enter the actual fee from the brochure or offer letter. If actual fee ≤ ACM ceiling → system claims actual fee. If actual fee > ACM ceiling → system claims up to ACM ceiling only; excess is a self-funded deficit. Leave blank → system uses ACM ceiling rate.

## TABLE 7 — ROT (Remote Online Training)

> ROT is synchronous — live sessions via Zoom / Teams / Webex at a fixed schedule.
> Trainer and trainees are not in the same physical location.
> The venue question is asked for ROT In-House and ROT Public, and it decides the allowance: own premises / own location = meal allowance only (nobody travels, so no daily allowance); external venue / hotel = daily (travel) allowance only.

| Cost Item | Rate | ROT — Own Premise | ROT — External Venue |
|-----------|------|:-----------------:|:--------------------:|
| A) Trainer Allowance (internal trainer) | Full: RM1,400/day/group; Half: RM800/day/group | ✓ | ✓ |
| B) Course Fee — General (external trainer, no subsidiary) | Full: RM10,500/day/group; Half: RM6,000/day/group | ✓ | ✓ |
| B) Course Fee — General (external trainer, with subsidiary — HCC/SBL only) | Full: RM1,750/pax/day; Half: RM1,000/pax/day | ✓ Each co. pays per own pax | ✓ Each co. pays per own pax |
| B) Course Fee — Focus Area / Ind. Specific / Prof Cert | As charged, per pax | ✓ | ✓ |
| C) Travel (Daily) Allowance | <100km: RM250/day/pax; ≥100km: RM500/day/pax | ✗ Nobody travels | ✓ All trainees |
| D) Meal Allowance | Full: RM100/day/pax; Half: RM50/day/pax | ✓ All trainees (host and branches, each at own workplace) | ✗ External venue covers meals |
| G) Air Ticket | Actual airfare | ✗ Not applicable | ✗ Not applicable |
| H) Chartered Transport | As per quotation | ✗ | ✓ |
| I) Consumable Materials | RM100/group; >RM100 itemised invoice | ✓ | ✓ |

**Notes:**
- Schemes: HCC, SBL, SLB.
- Air ticket is NOT claimable for ROT — trainer delivers online; trainees attend from their location.
- This follows HRD Corp's rule that ROT is treated the same as face-to-face: the allowance depends on where trainees physically are. That is why the venue is asked for both ROT In-House and ROT Public. Trainees who gather at an external venue / hotel get the daily allowance, exactly as for face-to-face. Trainees who join from their own premises / own location don't travel, so they get the meal allowance.
- SLB cost mode: group rate ÷ total pax × each employer's pax. Never public rate.
- SLB consumables: organising employer only.
- **Actual Course Fee (External trainer):** Enter the actual fee from the brochure or offer letter. If actual fee ≤ ACM ceiling → system claims actual fee. If actual fee > ACM ceiling → system claims up to ACM ceiling only; excess is self-funded. Leave blank → system uses ACM ceiling rate.

# PART C — CROSS-CUTTING RULES

## TABLE 9 — Rules Applying to All Training Types

| Rule | Detail |
|------|--------|
| C vs D mutual exclusivity | Each person claims C (travel) OR D (meal) — not both |
| External trainer personal claim | Ext. trainer may claim C (travel) only — not D (meal) |
| External trainer — air ticket | Eligible only when: (a) branch/sub trainees are present (long-distance training context), OR (b) venue is external hotel. At own premise with no branches/subs, external trainer is treated as local — no air ticket entitlement |
| Overseas trainer — air ticket | Always eligible — trainer flew in from overseas regardless of venue or participant composition |
| Extra travel day — local | Staff ≥100km: +1 extra day at Row C rate (full day training only) |
| Extra travel days — overseas | Up to +2 extra days of daily allowance (RM1,500/day × 50%) |
| 75% attendance | Min 75% attendance required. Allowances prorated by attendance |
| Half-day minimum | 4 hours minimum = half day. All items at half-day rate |
| Prorating — less than 5 pax | A and B: (rate ÷ 5) × actual pax |
| Subsidiary present (HCC/SBL) | Course fee switches from group rate to RM1,750/pax/day for both external and overseas trainer. Each company pays per own pax. **Subsidiaries only affect the course fee calculation and split. All other allowable costs (travel, meal, air ticket) are calculated for the Host Company and its Branches only.** Each subsidiary must submit their own separate HRD Corp grant application to claim travel, meal, and air ticket allowances. |
| SLB cost split | Group rate ÷ total pax × each employer's pax. Never public rate. Each participating employer is entered via the "+ Add Participating Employer" button — requires Employer Name, HRD Corp Employer Code, and Pax count. |
| SLB consumables | Organising employer only |
| Public / overseas pax cap | Max 9 pax per employer. Pax 10+ self-funded |
| Seminar min pax | In-house event: 51 total. Public event: 51 per TP |
| LTM | In-house training only. Requires HRD Corp Special Approval Letter at grant stage |
| Max pax — Non-Technical in-house | **Hard limit**: 50 pax × number of trainers (Employer's Circular No. 3/2024). Exceeding this blocks the claim. In-house training only — NOT applicable to Public Training or Seminar/Conference |
| Max pax — Technical in-house | **Hard limit**: 25 pax × number of trainers (Employer's Circular No. 3/2024). Exceeding this blocks the claim. In-house training only — NOT applicable to Public Training or Seminar/Conference |
| Audit risk threshold | >25 pax: HRD Corp may request audit documentation |
| Actual Course Fee input | Applies when trainer type is External or Overseas (in-house, ROT). Enter the actual fee from the brochure/offer letter. If actual ≤ ACM ceiling → system claims actual fee. If actual > ACM ceiling → system claims only ACM ceiling; deficit is self-funded by employer. Leave blank → system uses ACM ceiling only. For Internal trainer, this field is not shown (trainer allowance is a fixed ACM rate, not a quoted provider fee). |
| Deficit display — per company | When subsidiaries are present and the ACM ceiling is applied, the deficit is shown at both the total level AND per individual company row (Host Company / each Subsidiary). Each company row shows: HRD Corp pays RMxxx / 💰 Deficit RMxxx to be funded from employer's own budget. Deficit per company = (actual fee/pax − ACM ceiling/pax) × that company's pax count. |

# PART D — SUPPORTING DOCUMENTS REQUIRED
Source: ACM Guide (September 2025) — Type of Programmes section + Allowable Cost Matrix "Supporting Document(s)" column

## Tailoring Rules

| Condition | Impact on Document List |
|-----------|------------------------|
| Internal trainer | Item 3 (Invoice for course fees) is **omitted** — internal trainer generates Trainer Allowance, not a course fee |
| External / Overseas trainer | Item 3 (Invoice for course fees) **included** |
| Subsidiaries present (HCC / SBL) | **Letter from Host Company confirming subsidiary participation** is **included** — names, HRD Corp codes, relationship confirmation, participants, authorised signature |
| Subsidiaries present (SLB) | Covered by Joint Training Letter — no separate host letter required |
| SBL + External / Overseas trainer | Vendor / service agreement **included** |
| SBL + Internal trainer | Vendor / service agreement **omitted** — no external vendor |
| SLB scheme | Joint Training Letter **included** |
| ROT (Remote Online Training) | System Generated Attendance Report **included** |
| Hotel / external venue | Chartered transport invoice **included** (if any) |
| Own premise | Chartered transport invoice **omitted** — not eligible at own premise |
| In-house training type | Special Approval Letter **included** (for LTM, if any) |
| Public / elearning / overseas / seminar / development | Special Approval Letter **omitted** — LTM not applicable |
| Focus Area / Industry Specific / Certification | Acknowledgement Letter **included** |
| Development programme | Syllabus + Confirmation letter + (SBL: MQA certificate) — trainer profile omitted |
